### `// TRANSMISSION 000 — WHO'S BEHIND THE CODE?`

I’m **hanxww** — an independent developer turning *“what if?”* into working software.

I build **developer tools**, **desktop utilities**, and **experiments in user control**. My favorite kind of software is powerful under the hood, calm on the surface, and honest about what it does.

> **The mission:** Less friction. Fewer mysteries. More agency for the person using the software.

<details>
<summary><b>⚔️ 01 / AgentArena — see the engineering behind the arena</b></summary>
<br />

**[Explore AgentArena →](https://github.com/hanxww/AgentArena)**

Run different coding agents on **the same engineering task**, from the **same base commit**, in **isolated Git worktrees**. Run real project checks, inspect diffs, compare results, and choose whether to apply the winner.

`Node.js` · `Git` · `Codex` · `Claude Code` · `Gemini CLI` · `OpenCode` · `Local-first`

**Why it matters:** Public benchmark scores can't tell you which agent is right for *your* repository. AgentArena lets your own checks help decide.

</details>

<br />

<a href="https://github.com/hanxww/CleanMyFiles"><img src="./assets/cleanmyfiles.svg" alt="CleanMyFiles — privacy-first desktop storage analyzer" width="100%" /></a>

<details>
<summary><b>🧹 02 / CleanMyFiles — understand first, clean second</b></summary>
<br />

**[Explore CleanMyFiles →](https://github.com/hanxww/CleanMyFiles)**

A desktop file analyzer for examining disk usage, finding **exact duplicates**, and reviewing large or old files — **without automatic deletion**. Scans run locally, and the final choice always stays with you.

`Rust` · `Tauri 2` · `BLAKE3` · `Local-first` · `Review before action`

**Why it matters:** A cleanup app should make you confident, not make decisions about your files for you.

</details>

<details>
<summary><b>🎛️ 03 / vayGram — customization without chaos</b></summary>
<br />

**[Explore vayGram →](https://github.com/hanxww/vayGram)**

An **early-development** experiment exploring extreme customization for a Telegram Android client: settings scopes, visibility levels, presets, and a modular approach to UI changes.

`Android` · `VayCore` · `Customization` · `Experimental`

**Why it matters:** Customization should unlock possibilities without turning everyday use into a chore.

</details>
